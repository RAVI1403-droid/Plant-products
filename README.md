# Plant Products 🌿

A simple and responsive plant products website created using React, TypeScript, Vite, and Tailwind CSS.  
This project showcases different indoor plants with a modern UI design and reusable React components.

---

## Features

- Responsive Navbar
- Hero Section with banner image
- Trending Plants section
- Top Selling Plants section
- Customer Reviews section
- Reusable React Components
- Mobile, Tablet, and Desktop responsive design
- Modern UI inspired by Figma design

---

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
